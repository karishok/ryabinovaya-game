# Где мы остановились

Записка для следующей сессии. Работа шла в облачной сессии Claude Code; дальше
она переезжает на локальный компьютер, потому что приложение решено делать на
Flutter, а для него нужны SDK, эмулятор и сборка под телефон.

- Ветка: `claude/game-upgrade-r9lt5c`, PR #3 в `main` (не смержен).
- Тесты: `node --test tests/*.test.js` — 352 зелёных.
- Запуск: открыть `index.html` в браузере, сборки нет.

## Что это за игра сейчас

Склад-распределительный центр «Рябиновая». Два режима.

**Кампания — 10 смен.** Первые две вводные, их ведёт карточка «Сейчас» под
схемой. С третьей смены подсказок нет:

- Работу выдаёт ТСД — по одному заданию, кнопка «Принять». Первым он даёт то,
  чей фургон уходит раньше, затем срочное, затем остальное по порядку.
- Срочные задания (приехала фура, дозаказ, снять паллету отменённой заявки)
  можно взять поверх начатого — собранное на паллету возвращается на полку.
- Заявка даркстора из одной зоны — одно задание и одна паллета, даже если
  товаров несколько.
- В шести сменах один фургон уходит по часам (15–50 секунд). Не успел —
  заявка сорвана, звёзды потеряны.
- Доска под схемой — табло, нажать на неё нельзя.

**«Поток».** Склад работает сам: фуры приходят волнами, фургоны ждут минуту.
Четыре станции — приёмка, размещение, отбор, погрузка. Вход — кнопка на
стартовом экране смены.

## Решения, которые принял владелец продукта

Их легко нечаянно откатить — не откатывать.

1. **Зону размещения игра не подсказывает никогда.** Что воде место в сухаче,
   а мороженому в заморозке, игрок решает сам: «в этом суть игры». Нет строки
   в накладной, нет подсветки верной вывески, нет кнопки-автопилота. После
   приёмки одинаково пульсируют все вывески. Верная зона называется только
   после ошибки, в отчёте.
2. **Заявки с доски не выбирают.** В жизни кладовщик заявки не выбирает — они
   приходят на ТСД.
3. **«Отложить» убрано.** Было три отложения на смену; оказалось неясно, когда
   откладывать. Не возвращать.
4. **Сроки должны быть реальными.** «Успевать реально, но если не успел —
   потерял баллы». Срок 55 секунд при работе на 7 — «дофига».
5. **Вводных смен две, всего десять.**
6. **Бананов нет, есть масло.**
7. **Порядок остановок в каждой смене свой** — для этого добавлены дарксторы
   «Ховрино» и «Медведково».
8. Кнопки выбора смены на стартовом экране были отвергнуты как некрасивые.
   Есть только «Начать с первой смены».

## Открытые вопросы

- **Вид игры.** Четыре варианта лежат в `docs/redesign/`, выбор не сделан.
- **Подложка склада.** Сейчас в игре фотография; в макетах — временный SVG.
  Промт для генерации там же.
- **«Поток» не переведён на очередь ТСД**: в нём по-прежнему нажимают на
  строки фургонов.
- **Сроки ухода фургонов** подобраны по оценке скорости действий (принять —
  2 с, паллета — около 4 с), живым игроком в новых числах не проверены.
- Описание PR #3 отстаёт от кода: в нём нет очереди ТСД, сборных заявок,
  новых дарксторов и удаления «Отложить».

## Как устроен код — и что это значит для Flutter

Правила игры отделены от экрана, и это главное, что стоит сохранить.

| Файл | Что в нём | Зависит от DOM |
|---|---|---|
| `game-engine.js` | товары, паллета, фургон, приёмка, маршрут | нет |
| `levels.js` | десять смен как данные | нет |
| `scoring.js` | звёзды, прибыль, причины в отчёте | нет |
| `app-state.js` | редьюсер смены, очередь ТСД, уход фургонов | нет |
| `scene-view.js`, `tsd-view.js` | что показать на схеме и на ТСД | нет |
| `flow-engine.js`, `flow-view.js` | режим «Поток» | нет |
| `app.js`, `flow-app.js` | отрисовка и нажатия | да |
| `index.html`, `styles.css` | разметка и вид | да |

Первые восемь файлов — чистые функции над обычными объектами. Их можно
переносить на Dart почти построчно, а тесты из `tests/` служат спецификацией:
`task-queue.test.js`, `flow-balance.test.js` и `next-step.test.js` проходят
смены ботами и проверяют, что они решаемы. Перенести этих ботов первыми —
самый дешёвый способ убедиться, что Dart-версия играет так же.

Заново писать придётся только экран: `app.js`, `flow-app.js`, разметку и стили.
Раз вид всё равно переделывается, старый CSS переносить не нужно.
